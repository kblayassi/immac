# Déterminer l'équation cartésienne d'un cercle

## Comment faire ?

!!! methode "Comment déterminer l'équation cartésienne d'un cercle ?"
    On considère l'équation $\textcolor{gray}{x^2 + y^2 + 6x - 4y + 9 = 0}$. Déterminer s'il s'agit d'un cercle, si oui, donner son équation cartésienne puis ses éléments caractéristiques.

    1. **Écrire, si possible, l'équation sous la forme $\textcolor{gray}{(x - x_A)^2 + (y - y_A)^2 = r^2}$.**

       $$\textcolor{gray}{x^2 + y^2 + 6x - 4y + 9 = 0 \;\Leftrightarrow\; (x^2 + 6x) + (y^2 - 4y) + 9 = 0}$$
       $$\textcolor{gray}{\Leftrightarrow\; [(x+3)^2 - 9] + [(y-2)^2 - 4] + 9 = 0}$$
       $$\textcolor{gray}{\Leftrightarrow\; (x+3)^2 + (y-2)^2 = 4}$$

    2. **En déduire les éléments caractéristiques : il s'agit d'un cercle de centre $\textcolor{gray}{A(x_a ; y_a)}$ et de rayon $\textcolor{gray}{r}$.**  
       Il s'agit donc du cercle de centre $\textcolor{gray}{A(-3 ; 2)}$ et de rayon $\textcolor{gray}{2}$.
