# 🐍 Le parcours Python

Le programme de mathématiques de Première demande de savoir programmer en Python, et en
particulier de manipuler des **listes**. Ce parcours t'y emmène pas à pas, depuis les
bases de Seconde, avec les suites et le second degré comme terrain de jeu.

[Ouvrir le parcours :material-arrow-right:](../../parcours-maths-1e/){ .md-button }

## Comment ça marche

- Le parcours est découpé en **neuf séances courtes**. Chacune commence par une
  **découverte** guidée, puis des **exercices** pour t'entraîner.
- Les étapes s'ouvrent **les unes après les autres** : chaque réussite débloque la
  suivante, aucune notion n'arrive avant d'avoir été expliquée.
- Tu écris ton code **dans la page** : rien à installer, ton travail est vérifié
  automatiquement, et des **coups de pouce** t'attendent si tu bloques.
- Ta progression est **enregistrée toute seule** dans ce navigateur : tu peux t'arrêter
  à tout moment et reprendre plus tard.

!!! tip "Tu travailles seul, chez toi"
    Rien n'est noté : essaie, trompe-toi, recommence. Lis chaque consigne jusqu'au bout,
    exécute ton programme souvent, et utilise les coups de pouce sans hésiter. Si tu
    restes bloqué malgré le dernier indice, note ta question : on en parlera en classe.

!!! warning "Si tu changes d'appareil"
    Ouvre le menu **☰** en haut à droite du parcours et clique sur **Télécharger ma
    progression**. Sur le nouvel appareil, ouvre le même menu et dépose le fichier obtenu.
    Un ordinateur ou une tablette avec clavier est bien plus confortable qu'un téléphone.

## Les séances

| # | Séance | Ce que tu travailles |
|---|--------|----------------------|
| | **Partie 1 — Les rappels de Seconde** | |
| 1 | Calculer et mémoriser | `print()`, opérations, variables : image d'un nombre, discriminant |
| 2 | Décider | `if`, `elif`, `else` : signe du discriminant, racines d'un trinôme |
| 3 | Répéter | `for` et `while` : termes d'une suite, somme, seuil |
| 4 | Les fonctions | `def` et `return` : *f*(*x*), *u*(*n*), `delta(a, b, c)` |
| | **Partie 2 — Les listes** | |
| 5 | Créer une liste et lire ses éléments | crochets, indices, `len()` |
| 6 | Modifier et remplir une liste | `append()`, `sum`, `min`, `max` : la liste des termes d'une suite |
| 7 | Parcourir une liste | moyenne, comptage, tableau de valeurs |
| 8 | Les listes en compréhension | construire et filtrer en une ligne |
| | **Partie 3 — Le défi final** | |
| 9 | Le défi final | tout ensemble, et un sujet libre |
