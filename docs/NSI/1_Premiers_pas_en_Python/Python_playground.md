# Playground Python 🐍

Cet éditeur exécute du **vrai Python** directement dans ton navigateur : rien à installer,
rien à envoyer sur un serveur. Ton code reste sur ton ordinateur et est **conservé d'une
séance à l'autre**.

!!! info "Mode d'emploi"
    - **Exécuter** (ou ++ctrl+enter++) lance ton programme ; l'affichage apparaît dans la console.
    - :fontawesome-solid-trash: vide l'éditeur, :fontawesome-solid-arrow-rotate-right: remet le code de départ.
    - Quand ton programme rencontre un `input()`, il s'arrête et attend : la question s'affiche
      dans la console, tu tapes ta réponse **directement à la suite**, puis ++enter++ pour
      continuer. Exactement comme dans un vrai terminal.
    - Le tout premier lancement demande quelques secondes : Python doit d'abord être téléchargé.
