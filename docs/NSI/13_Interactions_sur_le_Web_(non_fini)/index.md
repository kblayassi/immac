# Interactions sur le Web 🖱️🌐

Au chapitre 7, nous avons construit des pages web **statiques** avec HTML et CSS.
Il est temps de les rendre **vivantes** : réagir à un clic, remplir un formulaire,
échanger des données avec un serveur.

!!! info "Chapitre à rédiger"
    Contenu prévu par la progression 2026-2027 (2 à 3 semaines) :

    - Identifier les **composants graphiques** permettant d'interagir avec une application Web
    - Identifier les **événements** que les fonctions associées à ces composants savent traiter
    - Analyser et modifier les méthodes exécutées lors d'un **clic sur un bouton**
    - Distinguer ce qui est exécuté **côté client** ou **côté serveur**, et dans quel ordre
    - Distinguer ce qui est **mémorisé dans le client** et ce qui est retransmis au serveur
    - Reconnaître **quand et pourquoi** la transmission est chiffrée
    - Analyser le fonctionnement d'un **formulaire** simple
    - Distinguer les transmissions de paramètres par requêtes **POST** ou **GET**
      (selon le type de valeurs et leur confidentialité)

    Outils : **JavaScript** et protocole **HTTP**.
