# 📚 Le parcours interactif

Ce chapitre **au complet**, mais autrement : découpé en petites étapes qui se
valident une par une, avec le cours, les exercices, les TP et des défis supplémentaires.

[Ouvrir le parcours :material-arrow-right:](../../../parcours-nsi-ch4/){ .md-button }

!!! tip "Même contenu, autre chemin"
    Rien n'est retiré des [pages de cours](index.md) : les deux versions coexistent.
    Le cours classique reste la référence à relire avant un devoir ; ce parcours est
    fait pour **travailler**, pas pour lire.

## Comment ça marche

- Le chapitre est découpé en **12 séquences courtes**, chacune avec sa **découverte**
  pas à pas, ses **exercices** et ses **défis**.
- Les étapes s'ouvrent **les unes après les autres** : chaque réussite débloque la
  suivante, aucune notion n'arrive avant d'avoir été vue.
- Tu écris ton code **dans la page** : rien à installer, correction automatique,
  coups de pouce à la demande.
- Ta progression est **enregistrée toute seule** dans ce navigateur.

!!! warning "Si tu changes d'ordinateur"
    Ouvre le menu **☰** en haut à droite du parcours et clique sur **Télécharger ma
    progression**. Sur le nouveau poste, ouvre le même menu et dépose le fichier obtenu.

## Les séquences

Les séquences sont regroupées en **quatre parties**, qui suivent les pages du cours.

| # | Séquence | Ce que tu travailles |
|---|----------|----------------------|
| | **Partie 1 — Les listes** | |
| 1 | Créer une liste et lire ses éléments | crochets, indices, `len()`, indices négatifs |
| 2 | Modifier une liste | `L[i] = …`, `append()`, `sum`, `min`, `max`, `in` |
| 3 | Parcourir une liste | par élément, par indice, l'accumulateur |
| 4 | Les listes en compréhension | construire et filtrer en une ligne |
| | **Partie 2 — Matrices et mémoire** | |
| 5 | Les matrices | listes de listes, `M[i][j]`, doubles boucles |
| 6 | Ce qui se passe en mémoire | adresses, alias, `==` et `is`, copies |
| | **Partie 3 — Premiers algorithmes** | |
| 7 | De l'algorithme au programme | organigramme, pseudo-code, algorithme d'Euclide |
| 8 | Parcours total, parcours partiel | compter, rechercher une occurrence |
| 9 | Où se trouve la valeur ? | première occurrence, toutes les occurrences |
| 10 | Extremum et moyenne | record, position du record, moyenne |
| | **Partie 4 — Les chaînes de caractères** | |
| 11 | Une chaîne est une séquence | indexation, immuabilité, `+` et `*` |
| 12 | Parcourir et découper une chaîne | parcours, tranches, chiffre de César |

!!! info "Et les exercices et les TP du chapitre ?"
    Les **26 exercices** et les **3 TP** du chapitre sont tous repris dans le parcours,
    à leur place dans la progression. Les exercices « sans ordinateur » sont devenus des
    questions à choix multiples et des prédictions.
