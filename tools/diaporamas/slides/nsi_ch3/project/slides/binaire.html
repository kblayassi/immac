Le système binaire (base 2)

Définition

  • Le système binaire est le système de numération de base b = 2.
  • Il n'utilise que deux chiffres, 0 et 1, appelés bits (binary digit).
  • Un regroupement de 8 bits est appelé un octet.
  • Il unifie la logique (Vrai/Faux), le calcul et l'électronique : idéal pour l'informatique.
  • Avec n bits, on représente 2ⁿ nombres : les entiers naturels de 0 à 2ⁿ − 1.
