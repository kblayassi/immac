L'exemple typique 😱

Énoncé · Que répond Python à 0.1 + 0.2 == 0.3 ?

>>> 0.1 + 0.2 == 0.3
False
>>> 0.1 + 0.2
0.30000000000000004

Python ne trouve pas l'égalité ! 0,1 et 0,2 sont approchés en binaire, ce qui crée un petit décalage.

Info

Pourquoi ça arrive ?

  • Les nombres sont codés en binaire flottant, avec un nombre limité de bits (32 ou 64).
  • 0,1 a une écriture infinie en binaire.
  • L'ordinateur tronque ou arrondit : c'est l'erreur d'approximation.
