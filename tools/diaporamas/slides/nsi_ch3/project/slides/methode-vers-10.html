Convertir vers la base 10 🔁

Méthode

De la base b vers la base 10

On décompose le nombre selon les puissances de la base, en partant de la droite. Si N s'écrit aₙ aₙ₋₁ … a₁ a₀ en base b, alors :

N = aₙ×bⁿ + aₙ₋₁×bⁿ⁻¹ + … + a₁×b¹ + a₀×b⁰

Astuce

  • Puissances de 2 : 1, 2, 4, 8, 16, 32, 64, 128, 256…
  • Puissances de 8 : 1, 8, 64, 512… · de 16 : 1, 16, 256, 4096…
  • En hexadécimal : A = 10, B = 11, C = 12, D = 13, E = 14, F = 15.
