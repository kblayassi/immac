Les limites du bit de signe

Attention

Problèmes rencontrés

  • Il y a deux représentations de 0 : 0 0000 et 1 0000 (sur 5 bits).
  • Les opérations deviennent difficiles : 6 + (−6) donne 0 0110 + 1 0110 = 1 1100, soit −12 au lieu de 0 !
  • Ce système n'est pas utilisé en pratique dans les ordinateurs modernes.
