Partie 3 · Les décimaux et les réels

Comparer deux flottants ⚖️

❌ À éviter : comparer avec ==

>>> a = 0.1 + 0.2
>>> a == 0.3
False

✅ Plus fiable : tolérer un écart epsilon

>>> abs((0.1 + 0.2) - 0.3) < 1e-9
True

À retenir

  • Les ordinateurs ne représentent que des approximations de la plupart des réels.
  • Cela peut provoquer des erreurs dans les comparaisons ou les calculs en chaîne.
  • Pour comparer deux flottants, on utilise abs(a - b) < epsilon.
