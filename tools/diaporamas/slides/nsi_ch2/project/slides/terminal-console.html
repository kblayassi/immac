Terminal ou console ?

Info

Différence entre le terminal et la console

Le terminal est une application qui ouvre une console dans une interface graphique ; il permet de lancer des commandes.

La console est une interface textuelle : une « communication » homme-machine avec seulement un écran et un clavier.

Dans la pratique, les deux s'utilisent de la même manière.

Astuce

En cas de problème avec l'interface graphique, Ctrl + Alt + F3 à Ctrl + Alt + F6 ouvrent une console en plein écran, qui peut permettre de résoudre le dysfonctionnement.

Sous Zorin OS (comme sous Ubuntu), on revient à l'interface graphique avec Ctrl + Alt + F1 ou Ctrl + Alt + F2.
