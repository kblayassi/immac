Partie 3 · Les droits d'accès

Organisation des utilisateurs 👥

root, le super-utilisateur 🛠️

  • aussi appelé administrateur
  • peut modifier, supprimer et accéder à tout le système
  • à utiliser avec parcimonie pour éviter les erreurs critiques

Les groupes 📂

  • réunissent plusieurs utilisateurs
  • on accorde des droits au groupe…
  • … et tous ses membres en bénéficient

À retenir

root a tous les pouvoirs. Plutôt que de gérer les droits un par un, Linux attribue les permissions à un groupe entier.
