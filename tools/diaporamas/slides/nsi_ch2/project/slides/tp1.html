TP1 · Installation de Linux 🐧

Installer une distribution Linux, Zorin OS, sur un disque dur externe grâce à une clé USB bootable : notre environnement de travail pour toute l'année en NSI.

Objectifs 📌

  • Télécharger une image d'installation de Linux.
  • Créer une clé USB bootable.
  • Démarrer sur cette clé et installer Linux sur un disque dur externe.

Matériel 🧰

  • une clé USB de 8 Go ou plus
  • un disque dur ou SSD externe de 128 Go ou plus
  • l'image ISO de Zorin OS Core
  • le logiciel Rufus (Windows)
