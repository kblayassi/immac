Repères historiques

1969

Première version d'Unix. Un grand nombre de systèmes ultérieurs s'en inspirent.

1984

Mac OS (Apple) : avec le Macintosh, la souris, inventée dans les années 1960, devient grand public.

1985

Première version de Windows, qui équipe aujourd'hui la grande majorité des ordinateurs personnels.

1991

Première version de Linux, gratuit, open source, utilisé sur divers matériels.
