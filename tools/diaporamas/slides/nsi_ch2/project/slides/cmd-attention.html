Partie 2 · La ligne de commande

Supprimer, agir ailleurs

Attention

Suppression avec rm 🚨

rm ne passe pas par la corbeille : la suppression est définitive. Pour un répertoire non vide, il faut l'option -r (suppression récursive) : elle supprime tous ses fichiers et sous-répertoires.

rm -r nom_du_répertoire

Info

Agir hors du répertoire courant 📂

Les commandes acceptent aussi un chemin relatif ou absolu : pas besoin de se déplacer pour agir sur un fichier situé ailleurs.
