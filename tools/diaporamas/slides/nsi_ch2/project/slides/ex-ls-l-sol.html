Énoncé · Les droits de EDS, Maths, SNT et NSI

Info

Dans cet exemple

  • EDS, Maths, SNT : le propriétaire et le groupe ont tous les droits ; les autres ont lecture et exécution.
  • NSI : le propriétaire a tous les droits, le groupe seulement la lecture, les autres lecture et exécution.

Attention

Conséquence surprenante

Un membre du groupe ne peut pas entrer dans NSI (pas de x), alors que les autres utilisateurs le peuvent !
