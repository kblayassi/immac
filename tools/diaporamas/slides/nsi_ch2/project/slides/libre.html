Libre ou propriétaire ? 🔓

Tous ces systèmes remplissent les mêmes fonctions, mais certains sont libres tandis que d'autres sont propriétaires.

Définition

Un logiciel libre (open source) est un logiciel dont le code source est accessible et modifiable. Il peut être consulté, modifié et redistribué sans restriction financière.
