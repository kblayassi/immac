IMMAC KOXO

Proxy automatique

Configure ton Mac ou PC une seule fois. Le proxy s'activera et se désactivera tout seul selon le réseau Wi-Fi.

ℹ️ Suis les étapes ci-dessous depuis le réseau Wi-Fi IMMAC KOXO (à l'école). Tu n'auras plus jamais à toucher aux paramètres proxy manuellement.
1
Télécharge le script d'installation
Clique sur le bouton ci-dessous pour télécharger le fichier install-proxy-immac.ps1.
2
Ouvre PowerShell en administrateur
Appuie sur Windows + X puis clique sur "Terminal (administrateur)" ou "Windows PowerShell (administrateur)".
3
Autorise l'exécution des scripts
Colle cette commande dans PowerShell et appuie sur Entrée :
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
Si une confirmation est demandée, tape O puis Entrée.
4
Lance le script d'installation
Dans PowerShell, va dans le dossier Téléchargements et lance le script :
cd "$env:USERPROFILE\Downloads"; .\install-proxy-immac.ps1
Une fenêtre bleue s'ouvre et t'indique la progression. Attends le message "Installation terminée".
Télécharger le script
✅
Une fois installé, plus rien à faire — connecte-toi au Wi-Fi IMMAC KOXO et le proxy s'active automatiquement. Sur ton réseau à la maison, il se désactive tout seul.
